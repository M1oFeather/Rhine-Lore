## 执行顺序建议

1. **P0-1 数据持久化**（架构性，先做，避免后面返工）；
2. P0 其余项（设置/故事/反馈补全）；
3. 跑一次通用标准 J 级自动验收（滚动 + 引导 + 控制台错误）；
4. P1 按 8→17 顺序逐项落地，每项跑 page-acceptance.md；
5. P2 进入体验增强阶段。

## 验收方式

- 每阶段结束：CDP 自动检查（outer=0、无 JS 错误、引导要素存在）+ 手动主链路；
- 数据安全专项：杀进程/清缓存/重启三类场景必须通过；
- 动画专项：reduced-motion 与常规模式各验一次。
