# Rhine-Lore 全量设计评估

评估日期：2026-08-12
方法：CDP 逐页实测（滚动 / 信息密度 / 面板高度）+ 代码走查 + V2.1 设计原则对照

> 引导与交互专项方案见 [interaction-guidance.md](interaction-guidance.md)。

## 一、全局现状

### 优点

- 整页滚动基本清零（除写作/阅读例外），符合 App 化方向；
- 视觉令牌统一：色板、18px 圆角、双层阴影、实心 Material 图标；
- AI 对话已提升为一级全屏页，操作权限与版本管理完整；
- 固定视口页（首页/世界观/角色/资料库）已形成横向滑动的 App 模式。

### 问题

1. **无深色模式**：多处硬编码 hex，令牌未完全变量化；
2. **空状态不统一**：`el-empty` 与自定义空态混用；
3. **按钮密度高**：设置 18 个、AI 对话 17 个、正文 12 个；
4. **页面模式不统一**：卡片内联编辑（世界观/角色）、表单（故事）、表格（资料库）三种范式并存；
5. **反馈系统薄弱**：保存/加载/错误提示样式不一；
6. **移动端细节**：底部安全区、键盘避让未处理。

## 三、重设计优先级

### P0 · 体验硬伤（先做）

1. 空状态统一 + 侧边栏功能说明 + 首页创作路径卡（解决“不知道有什么用”，
   不做独立欢迎引导以避免后期冗余）；
2. 全局 toast 与操作反馈统一；
3. 设置页重构：分组卡片 + 折叠高级项 + 功能地图 + 消除 76px 溢出；
4. 故事档案：文风字段默认折叠。

### P1 · 模式统一

5. 世界观/角色：卡片只读 + 编辑抽屉；
6. 资料库：表格改卡片 + 抽屉式详情；
7. 正文：沉浸阅读（全宽、无干扰工具栏）；
8. 地图：全屏画布 + 浮动工具条。

### P2 · 进阶体验

9. 深色模式（令牌完全变量化）；
10. AI 对话流式输出；
11. 书架封面视觉、首页空态插画；
12. 动效体系与无障碍（滚动区可达、焦点管理）。

## 四、验收（DoD）

- 每页按评估表建议落地，且不回归滚动审计（outer=0、白名单外无内滚）；
- 设计令牌覆盖全部颜色，为深色模式铺路；
- 空状态/反馈/按钮密度达标（每页按钮 ≤ 8 个主操作）；
- 模拟器与网页版一致，滚动审计脚本入库并接入 CI。
