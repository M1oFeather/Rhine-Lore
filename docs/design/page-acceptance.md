# 每页全套验收标准

验收版本：P0（引导与反馈）完成后基线
适用范围：Android 模拟器（1080×2340）与网页版一致

## 全局验收（所有页面）

- [ ] 整页滚动 outer = 0（阅读/写作例外）；
- [ ] 固定页无隐藏裁切（overflow:hidden 容器 scrollHeight ≤ clientHeight）；
- [ ] 侧边栏每个入口有可见说明（展开态副标题 / 悬浮 tooltip）；
- [ ] 空状态 = 图标 + 说明 + 主 CTA + 次 CTA；
- [ ] 关键操作有 toast（成功/错误）与完成态；
- [ ] 按钮主操作 ≤ 8 个/页，触控高度 ≥ 36px；
- [ ] 点击卡片有按压反馈，抽屉/弹层动画 240ms 内完成；
- [ ] 顶部栏仅保留：菜单、标题、AI 状态（对话页除外）。

## 逐页验收

### 工作台
- [ ] 一屏固定（outer=0，无内滚）；
- [ ] 创作路径卡 5 步可点且跳转正确；
- [ ] 无项目时空状态（新建故事 / 先聊聊想法）；
- [ ] 项目横向滑动，无纵向滚动；
- [ ] AI 入口卡与快捷入口可用。

### 故事档案
- [ ] 固定框架，表单卡内滚，无整页滚动；
- [ ] 名称/类型/概要可直接编辑并自动保存；
- [ ] 文风字段可折叠，不占首屏；
- [ ] 保存有反馈（toast + 保存状态）。

### 世界观
- [ ] 固定页，卡片横向滑动；
- [ ] 空状态：说明 + 添加设定 + 看地图；
- [ ] 卡片可编辑/删除，删除有确认或可撤销；
- [ ] “一键放地图”入口可用。

### 角色
- [ ] 固定页，卡片横向滑动；
- [ ] 空状态：添加角色 / 让 AI 生成；
- [ ] 简单/完整编辑模式切换正常；
- [ ] 角色卡字段完整、保存有反馈。

### AI 对话
- [ ] 全屏固定，仅消息区滚动；
- [ ] 头部：☰、标题、上下文、模式切换、⋮；
- [ ] Enter 发送 / Shift+Enter 换行 / 附件可用；
- [ ] AI 提案 → 影响预览 → 确认执行/调整/取消；
- [ ] 执行后 toast + “已自动备份”提示；
- [ ] 思考动画与自动滚底正常。

### 正文
- [ ] 写作页允许滚动（例外）；
- [ ] 章节列表/目录抽屉、阅读设置抽屉可用；
- [ ] 阅读/编辑切换、自动保存、字数统计正确；
- [ ] 版本按钮：提交/历史/恢复（两次确认）可用；
- [ ] 空章节：创建第一章 / 先聊聊想法。

### 资料库
- [ ] 固定页（桌面三栏、移动横向栏）；
- [ ] 草稿/送审/入库/检索全流程可走通；
- [ ] 空资料有说明 + 去对话 + 保存当前章节；
- [ ] 版本/资料操作有 toast。

### 演化
- [ ] 固定页，状态标签页可切换；
- [ ] 开始/推进/分支/引导/重置可用且需确认；
- [ ] 小说视角与沙盘数据一致；
- [ ] 无隐藏裁切。

### 小说阅读
- [ ] 阅读页允许滚动；
- [ ] 章节条/目录抽屉/阅读设置可用；
- [ ] 生成下一章/重新生成本章/全局引导可用；
- [ ] 空演化引导去沙盘。

### 书架
- [ ] 阅读页允许滚动；书卡横向或列表布局合理；
- [ ] 空状态：导入 TXT / 去 AI 对话；
- [ ] 导入→拆章→阅读→AI 续写→保存 全链路；
- [ ] 版本按钮与恢复可用；
- [ ] 全书分析显示角色/设定/事实/伏笔。

### 地图
- [ ] 固定页，画布可用（拖拽/缩放/连线/编辑）；
- [ ] 空状态：添加地点 / 去世界观放地点；
- [ ] 地图数据与世界观联动。

### 设置
- [ ] 固定页签，内容区内滚，无 76px 裁切；
- [ ] 功能地图 12 项可见且直达正确；
- [ ] AI 通道配置/测试/DeepSeek 登录助手可用；
- [ ] 资料库连接状态与版本说明正确。

## 自动化检查

- 滚动审计（CDP）：12 页 outer=0、白名单外 inner=0、hidden 无溢出；
- 引导要素检查：路径卡/空状态/功能地图/导航说明存在；
- 交互冒烟：关键按钮可点击且跳转正确。
