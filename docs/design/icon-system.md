# Rhine-Lore 图标系统

版本：2026-08-14
方向：机能简约、语义明确、低装饰

## 基础规格

| 属性 | 规范 |
| --- | --- |
| 图标源 | Lucide Vue，通过 `GameIcon` 语义层统一调用 |
| 设计网格 | 24 x 24 |
| 默认尺寸 | 导航 20px；紧凑工具 16-18px；阅读工具 19-20px |
| 线宽 | 1.8px |
| 端点/连接 | 圆端点、圆连接 |
| 默认颜色 | 继承当前文本色 |
| 容器 | 28-34px 方形，6px 圆角，1px 中性边框 |

## 使用原则

1. 一个语义只使用一个图标。例如“资料库”始终使用 `database`。
2. 导航图标保持线性，不使用实心图标与线性图标混排。
3. 菜单、关闭、折叠、更多、搜索、书签等熟悉操作优先使用符号图标。
4. 清晰命令可以使用“图标 + 文本”，例如发送、保存和导入。
5. 品牌标识只代表 Rhine-Lore，不充当 AI 设置、发送或资料库图标。
6. 不用 Emoji、中文字符或箭头字符模拟功能图标。

## 状态

| 状态 | 图标颜色 | 容器 |
| --- | --- | --- |
| 默认 | 中性灰 | 透明或弱中性底 |
| 悬停 | 深色正文/浅色正文 | 弱面板底，边框增强 |
| 选中 | 蓝色 | 低饱和蓝底与蓝色边框 |
| 禁用 | 26%-40% 透明度 | 不增加彩色背景 |
| 成功 | 绿色 | 仅用于已连接、已保存、已完成 |
| 警告 | 琥珀色 | 仅用于需用户处理 |
| 错误 | 红色 | 仅用于失败或破坏性操作 |

## 无障碍与触控

- 纯图标按钮必须提供 `aria-label`；桌面端不熟悉操作同时提供 `title`。
- 装饰性图标使用 `aria-hidden="true"`，避免重复朗读旁边的文字。
- 图标视觉尺寸可以是 16-20px，但点击区域不小于 40px。
- 不能只依靠颜色表达选中或连接状态，应同时使用背景、边框、位置标记或文字。

## 实现边界

- 页面只引用 `GameIcon` 和产品语义名称，不直接引用 Lucide 组件。
- 图标库迁移只修改 `gameIconPack.ts`，不扩散到业务页面。
- 新增图标前先检查现有语义是否可复用，避免同义名称膨胀。
- 需要品牌插画、书籍封面或地图内容时使用真实视觉资产；功能图标不承担插画职责。
