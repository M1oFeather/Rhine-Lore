# Rhine-Lore 通用验收标准

状态：定稿 v1（2026-08-12）
适用：所有页面与功能，Android 模拟器与网页版一致。

## A. 信息架构与入口

- 每个功能有可见入口 + 一句话说明（导航副标题 / 功能地图 / 空态文案）；
- 首页路径卡到任意关键页 ≤ 2 次点击；
- 无“死胡同”页面：每页都有下一步 CTA；
- 功能地图覆盖全部功能，随时可查。

## B. 布局与视口

- 整页不滚动（阅读/写作白名单除外），outer=0 为硬性指标；
- 无隐藏裁切、无横向溢出；
- 移动端：安全区、键盘避让、单指可操作；
- 固定页 = 固定外框 + 白名单内滚，滚动条样式统一。

## C. 空态与引导

- 每个数据页空态 = 图标 + 说明 + 主 CTA + 次 CTA；
- 说明回答两个问题：这是干嘛的 / 我现在该做什么；
- 不做独立欢迎引导，引导融进页面本身（入口即引导）。

## D. 反馈与状态

- 每个写操作有反馈：成功 toast、失败原因、进行中 loading；
- 破坏性操作：二次确认 + 可回滚（版本快照 / 撤销）；
- 状态一致：保存即持久化、刷新不丢、AI/版本操作后页面自动同步；
- toast 统一位置与样式，错误信息可读。

## E. 交互与可用性（渐进引导）

- 触控目标：主操作 ≥ 44px、次操作 ≥ 36px；
- 不限制页面总按钮数，但**渐进引导**：
  - 首屏只呈现 1–3 个高优先级主操作；
  - 其余通过「更多」「展开」「抽屉」「折叠区」逐层暴露；
  - 可发现性验收：任意功能可经导航说明 / 功能地图 / 上下文 CTA 找到；
- 键盘可达、焦点管理正确、语义可朗读。

## F. 一致性

- 视觉令牌统一（圆角 / 颜色 / 阴影 / 图标风格）；
- 页面模式统一（固定页 / 横向卡 / 抽屉编辑）；
- 空态、toast、按钮、加载态全站一致。

## G. 性能与稳定

- 页面切换流畅，无掉帧卡顿；
- 控制台无 JS 错误、无白屏、无资源 404；
- 大文本（百万字级）按章加载，不阻塞 UI。

## H. 数据安全与持久化（硬性）

1. **自动保存**：所有可编辑内容（章节、对话、角色/世界观卡片、演化状态、
   书架阅读进度、AI 配置、版本说明）自动保存（防抖 0.8–2s），保存状态可见；
2. **关闭后保持**：杀进程 / 断电 / 重启后数据完整恢复；
3. **主存储在本机服务端** `data/` 目录（项目、书、演化、资料库、版本），
   浏览器 / WebView 只做缓存——清除缓存不影响数据；
4. **原子写入**：所有落盘使用 tmp + rename，损坏自动检测并提示，
   可经版本快照恢复；
5. **密钥只存本机**，不随导出/备份外泄明文；
6. **升级迁移**：数据结构变更自动迁移，不丢数据；
7. 验收场景：编辑中直接杀进程 → 重启数据在；清除浏览器缓存 → 数据仍在。

> 现状差距：故事项目主存在 localStorage（依赖浏览器缓存），需改造为
> 本机服务端为主存储（纳入 P0/P1 改造）。

## I. 动画与动效

- 过渡时长 ≤ 240ms，ease-out；
- 可点元素按压反馈 ≤ 100ms 内出现；
- 页面切换：淡入 + 轻微上移（120–180ms）；
- 抽屉 / 弹层滑入 240ms，不阻塞主内容；
- 仅使用 transform / opacity，不触发布局抖动；
- `prefers-reduced-motion` 时关闭非必要动画；
- AI 思考动画保留，并作为流式输出占位。

## J. 验收执行与分级

- **P0 阻断**：数据丢失、白屏、不可达、不可回滚——必须修复；
- **P1 重要**：引导/反馈/动效/一致性缺陷——本迭代修复；
- **P2 建议**：体验增强（封面视觉、深色模式、流式输出）——可缓；
- 自动化：CDP 滚动审计、引导要素检查、控制台错误检测；
- 手动：真机/模拟器 + 网页主链路回归；
- 每页验收按 `page-acceptance.md` 执行，标准升级时同步更新。
