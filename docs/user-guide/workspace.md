# 工作台与创作

## 首页是引导台

首页用于选择故事和进入任务，不承担完整编辑职责。故事以独立预览卡展示；人物、世界、地图、正文和资料库分别进入对应页面处理。顶栏持续显示当前项目，避免在对话、阅读和工作模式间切换时失去上下文。

## 两种创作入口

### 手动工作

在工作模式中直接维护：

- 卷、章和正文；
- 人物卡、身份、动机、弱点和关系；
- 势力、地点、规则与世界卡；
- 故事地图和章节转折；
- 待处理问题与全局创作指导。

AI 生成的内容应先作为可检查的草案，不应无提示覆盖正在编辑的正文。

### 对话创作

对话页适合用自然语言完成跨页面任务，例如：

```text
阅读当前项目，找出第三章人物动机不连贯的地方。
为“林岚”补充一个会影响第五章选择的秘密，但先让我确认。
把这段设定整理成资料草稿，不要直接入库。
```

一次写入的完整过程是：

1. 模型读取项目、书籍或附件上下文。
2. 模型生成回答和一个或多个待确认动作。
3. 界面显示工具名、目标和参数。
4. 用户逐项确认或拒绝。
5. 后端对项目/书籍写操作生成快照并执行。
6. 界面刷新相关数据；必要时在版本页恢复。

删除角色、章节、分支合并和沙盘重置属于高风险动作，应仔细核对范围。

## 附件与上下文

对话支持 TXT、项目和知识资料附件。当前一轮最多使用前五个附件，附件内容会进入模型上下文。在线模型模式下，不要附加不希望发送给模型服务商的敏感文本。

## 自动保存与版本

- 表单和正文编辑使用页面内保存机制；离开页面前确认保存状态。
- Agent 修改已有项目或书籍前会自动生成快照。
- 恢复旧版本前还会保存“恢复前快照”，避免恢复操作本身不可逆。
- 新建、导入、资料草稿和部分系统配置不属于项目/书籍快照范围，仍需完整备份。

## 演化沙盘

沙盘用确定性随机种子推进事件和人物关系，可手动选择分支、追加指导或重置。它用于探索可能性，不等同于正式正文；满意的结果应再整理进入章节或资料卡。
