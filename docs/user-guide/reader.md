# 小说阅读器

## 导入长篇小说

TXT 导入会先检测常见编码，再识别“第 X 章/卷”、`Chapter` 等标题。没有可靠标题时会按长度分段。原始文件不会被修改，书籍正文按章保存，以避免百万字文本每次整体载入。

导入时应检查：

- 书名与作者信息是否正确；
- 编码预览是否出现乱码；
- 卷名、章名和正文边界是否合理；
- 章节数量是否明显异常。

若预览乱码，请返回重新选择编码或源文件，不要继续分析；错误文本进入分析缓存后会扩大修复成本。

## 阅读模式

阅读器采用常规小说阅读布局，支持目录、上一章/下一章、进度、字体、字号、行距、段距、页宽、亮度和昼/纸/夜主题。沉浸阅读底栏的排版按钮在手机上始终可见，可在连续滚动与逐页翻页之间切换。卷标题与章节标题使用单独标题页，正文从下一阅读页开始。移动端会收紧边距并保留底部安全区。

逐页模式支持点击左右区域、键盘方向键和手机横向滑动。手势必须以水平方向为主，纵向拖动不会误触翻页；改变字号、行距或正文宽度后会按原阅读比例重新分页，不会跳回标题页。连续滚动模式不覆盖透明翻页区，可以正常选择文字、滚动和发起分支续写。

建议按场景调整：

| 场景 | 建议 |
| --- | --- |
| 手机竖屏 | 较窄页边距、适中字号、较大行距 |
| 桌面沉浸阅读 | 限制正文行宽，隐藏非必要面板 |
| 校对 | 较宽正文、显示目录与进度、使用编辑模式 |
| 夜间 | 暗色主题并降低对比度，避免纯黑纯白 |

## 任意位置创建 AI 分支

在阅读器或工作模式中选定章节位置后，可以建立续写分支。分支不会直接覆盖原文，而是在视觉分支树中形成新的故事路径。

1. 选择分支起点和必要的局部文本。
2. 输入方向、禁区或人物目标。
3. 生成候选续写并检查连续性。
4. 保留、重写或继续扩展该分支。
5. 需要正式创作时，将选定路径导入写作工作台。

删除分支时，后端会阻止删除仍有子节点的分支；应先处理后代路径。

## 百万字分析

长篇分析采用分片、汇总和树状合并流程，并按内容哈希复用缓存。任务状态会持久化，应用意外退出后可识别为暂停并继续，而不必从头分析。

分析前先查看预估，确认分片数量、模型调用规模和处理模式。推荐流程：

1. 先用快速或智能模式预览成本。
2. 按卷或选定范围开始，验证人物与设定提取质量。
3. 再扩展到全书，期间可暂停或取消。
4. 检查冲突事实和同名实体，不要直接把全部提取结果当作确定事实。
5. 将确认的人物、势力、地点、关系和地图导入工作台。

当前任务执行器运行在应用进程内，不是独立队列服务。进行超长分析时应保持应用运行，并避免同时启动过多高成本任务。
