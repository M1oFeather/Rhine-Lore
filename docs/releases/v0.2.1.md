# Rhine-Lore v0.2.1

发布日期：2026-08-15

v0.2.1 是阅读器、Android 身份信息、演示内容和模型通道的修订版本。

## 阅读器

- 阅读设置入口固定在沉浸阅读底栏，手机窄屏不再因顶部工具拥挤而找不到入口；
- 设置面板提供连续滚动/逐页翻页、昼/纸/夜背景、亮度、字体、字号、行距、段距、正文宽度、两端对齐和段首缩进；
- 翻页容器采用稳定的剩余视口高度，避免首次进入逐页模式时按标题内容高度错误分页；
- 横向滑动使用位移、方向和时长阈值，并抑制手势结束后的合成点击，避免一次滑动跳两页；
- 连续滚动模式不再挂载左右透明翻页按钮，文字选择、纵向滚动和分支续写互不冲突；
- 排版设置变化后按原页码比例重新定位，保留阅读位置。

## Android 与版本

- Python、Web、Android 和文档统一为 `0.2.1`，Android `versionCode` 更新为 `3`；
- APP 内部版本从 `ui/package.json` 读取，不再维护容易过期的界面常量；
- Android 自适应图标、圆形图标和 Android 13 单色图标统一使用 RL 标志；
- Android 的 Web 资源复制任务改为 `Sync`，构建时删除失效的哈希文件，避免 APK 长期累积旧前端资源。

## 默认演示

《灰烬月冠》现在包含“第一卷 伤月与灰烬”独立卷标题、序章、第一章至第十二章和卷尾，共 14 个目录项。第一卷完成从黑钟处刑、镜湖调查、名册真相到无声边境决战的完整故事弧，并保留可用于视觉分支树和下一卷创作的开放线索。

## DeepSeek V4

DeepSeek 预设使用官方当前模型名和 `https://api.deepseek.com`：

| AI 等级 | 模型 | 推理强度 | 适用场景 |
| --- | --- | --- | --- |
| 快速 | `deepseek-v4-flash` | `high` | 快速问答、灵感和低成本草稿 |
| 均衡 | `deepseek-v4-flash` | `max` | 日常对话、续写和改写 |
| 深度 | `deepseek-v4-pro` | `max` | 长篇分析、复杂分支和结构规划 |

Lore 会将 `thinking_enabled` 与 `reasoning_effort` 传给 Rhine-Vault 的 OpenAI 兼容通道。自定义和 OpenAI 预设仍可直接填写模型名称，不套用 DeepSeek 等级。

DeepSeek 官方说明 V4 Flash 与 V4 Pro 支持 1M 上下文、思考模式和 OpenAI ChatCompletions 接口；旧 `deepseek-chat` / `deepseek-reasoner` 名称已停止使用。参见 [DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) 和 [V4 发布说明](https://api-docs.deepseek.com/news/news260424/)。
