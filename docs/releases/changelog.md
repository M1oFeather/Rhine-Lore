# 更新日志

## v0.2.0（2026-08-15）

将早期功能原型整理为贯通阅读、分析、分支、工作台、对话和资料库的本地优先创作产品。

### 新增

- 面向新用户的工作台引导、故事卡选择、工作台/阅读器模式切换和后端连接状态；
- 产品级对话创作页、附件上下文、知识提取、写操作确认与版本快照恢复；
- TXT 编码检测与手动重选，修复 GBK/GB18030 等中文文本导入乱码；
- 百万字小说的分片规划、树状汇总、哈希缓存、暂停恢复和任务进度；
- 可从阅读器和工作模式任意位置发起的 AI 分支，以及可交互的视觉分支树；
- 书籍分析结果转换为工作台人物、势力、地点、关系和故事地图；
- 默认 Rhine-Vault Core、独立 Vault 接入和可选 Vault Web 安装/跳转流程；
- 原创哥特奇幻演示《灰烬月冠》，包含正文、人物、世界、地图和伏笔；
- 完整 MkDocs 文档站、Agent HTTP/工具/安全契约、系统评估与未来路线。

### 改进

- 重构首页、顶栏、侧边栏、对话、资料库、故事档案、阅读器和设置页布局；
- 阅读器增加滚动/翻页、目录、搜索、书签、字号、行距、页宽、主题和标题页；
- 全页面和弹窗适配手机安全区、软键盘、窄屏滚动与 Android 返回键；
- 更新机能简约图标、应用标记、交互状态、空状态和页面层级；
- 项目与书籍写操作加入自动版本快照，恢复前再次保护当前状态；
- Android WebView、文件导入与内嵌 Python/Vault 链路同步升级。

### 已知限制

- Lore HTTP API 尚无用户鉴权，CORS 允许任意来源，只适用于本机或受信局域网；
- Agent 写入确认仍由客户端实施，执行端尚无确认 nonce 与幂等键；
- 长篇分析任务运行在应用进程内，尚无独立持久任务队列；
- 前端关键页面仍集中在大型 `App.vue` 和全局样式文件中，后续需要模块化。

## v0.1.0（2026-08-11）

首个公开发布。

### 新增

- 正文写作与阅读：章节、阅读/编辑模式、字号/行距/白/米黄/夜间主题、自动保存与磁盘备份；
- 演化沙盘：确定性随机种子、回合推进、分支选择、自动播放、沙盘观演；
- 小说阅读：有限视角章节阅读、生成下一章、重新生成本章、全局引导；
- TXT 书架：自动拆章（第X章/Chapter 优先，无标题按字数分节）、百万字级按章存储与加载、
  阅读进度记忆；
- AI 创作：续写 / 改写 / 扩写、全书角色/设定/事实/伏笔分析、章节摘要、一致性约束；
- 资料库：内嵌知识库（草稿/送审/入库/检索/设定文档）；
- 安卓全内嵌版：Chaquopy + WebView，支持局域网网页访问（手机即后端）；
- 折叠侧边栏应用式布局。
