# Rhine-Lore

Rhine-Lore 是一个本地优先的小说工作台。它把阅读、正文编辑、对话创作、长篇分析、视觉分支和资料库放在同一条创作链路中，同时把 AI 的写操作留给用户确认。

当前版本为 **v0.2.0**。它适合作为单人、本机或受信局域网内的创作工具；现阶段不应作为公开互联网服务部署。

## 核心工作流

```text
导入小说 -> 编码识别与拆章 -> 阅读/分析 -> 从任意章节建立分支
                                          -> 提取人物、势力、地点 -> 写作工作台

创建项目 -> 设定与章节 -> 对话提出修改 -> 用户确认 -> 自动快照 -> 写入/恢复

资料草稿 -> 送审 -> 入库 -> 检索引用 -> 对话或正文创作
```

## 产品边界

- **Lore 负责创作体验**：项目、章节、阅读、分支、分析、写作工作台和对话编排。
- **Vault 负责知识治理**：资料生命周期、检索、审核与可选的独立 Web 管理界面。
- **AI 默认是建议者**：读取可自动执行；修改、删除和结构性操作必须先显示为待确认动作。
- **数据默认留在本机**：模型调用除外。启用在线模型时，相关提示词和附件片段会发送到用户配置的模型服务。

!!! warning "网络部署边界"
    当前 Lore HTTP 服务没有用户鉴权，并允许跨源访问。请优先绑定 `127.0.0.1`；使用 `0.0.0.0` 时只应位于可信局域网。不要直接暴露到公网。
