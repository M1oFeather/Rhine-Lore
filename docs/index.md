# Rhine-Lore 文档

Rhine-Lore 是一个本地优先的中文写作工作室：

- **正文**：章节阅读/编辑、阅读主题与排版设置、自动保存与磁盘备份；
- **演化沙盘**：回合制自动推进故事，支持分支选择、自动播放与有限视角小说；
- **小说阅读**：像追更一样阅读演化正文，章末生成下一章，支持引导与重写；
- **TXT 书架**：导入百万字级 TXT，自动拆章、按章加载，支持 AI 续写/改写/扩写
  与全书档案分析；
- **资料库**：本机内嵌知识库，草稿 → 送审 → 入库 → 检索全流程可用；
- **安卓全内嵌版**：Chaquopy 内嵌 Python 引擎，手机离线可用。

快速开始请阅读仓库根目录的 README（`README.md`）。
